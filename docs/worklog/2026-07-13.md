## 2. 実機ビルド不能問題の解消

- **症状**: `xcodebuild` で実機向けビルドが `No profiles for 'com.murakamiworks.rhythmark' were found` で失敗。無料Apple IDのプロビジョニングプロファイルは7日で期限切れになり、Automatic Signingが自動再生成できない状態だった
- **対処**: `-allowProvisioningUpdates` フラグを付与してビルドすることで署名を自動再生成し、ビルド成功
- **実機インストール**: `xcrun devicectl device install app` でiPhone 17(ペアリング済み)にインストール成功
- **起動時トラブルとその解消**:
  1. 初回起動時に `invalid code signature` エラー → iPhone側で「設定 > 一般 > VPNとデバイス管理 > デベロッパApp > 信頼」が未実施だったため(証明書単位の一度きりの手動作業、以降は不要)
  2. 信頼後、Debug構成でビルドしたアプリを起動すると `No script URL provided`(Metroパッケージャ未起動のため)→ Release構成に変更してJSバンドルをアプリ内に同梱することで、Mac側でMetroを起動していなくてもiPhone単体で動作するように修正
